# Otkup Polovnog Nameštaja

Prezentacioni sajt za otkup polovnog i stilskog nameštaja (Beograd i cela Srbija), spoj sadržaja sa dva postojeća sajta, u minimalnom dizajnu po uzoru na apple.com.

**Tehnologije:** statički HTML/CSS, Netlify Forms, Netlify Image CDN.

**Lokalno:** `netlify dev --port 8889`

**Plan razvoja:** vidi `PLAN.md`.
